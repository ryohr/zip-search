# 〒 郵便番号検索

住所の一部を入力すると、郵便番号の候補をすぐに表示するツールです。HTMLファイル1つとデータファイルだけで動き、サーバーもインターネット接続もいりません。

**ブラウザですぐ使う: https://ryohr.github.io/zip-search/**

## 使い方

手元で使う場合:

1. このリポジトリをダウンロードします(「Code」→「Download ZIP」で取得して展開)。
2. `index.html` をダブルクリックしてブラウザで開きます。
3. 検索欄に住所を入力します。

### 検索のしかた

- **住所の一部**: `日向市本町`、`本町` など
- **読みがな**: `ひゅうがし`、`ヒュウガシ`(ひらがな・カタカナのどちらでも探せます)
- **空白で絞り込み**: `日向市 本町` のように空白で区切ると、両方を含む住所だけを表示します
- **郵便番号から逆引き**: `883`、`883-0041` など
- **番地まで入力しても大丈夫**: 一致しないときは後ろから文字を削り、町域名まで一致する候補を表示します
- `/` キーで検索欄に移動します

### コピー

郵便番号の枠か「コピー」ボタンを押すと、クリップボードにコピーされます。「ハイフン付きでコピー」のチェックを外すと `8830041` の形でコピーします。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 検索画面(HTML・CSS・JavaScriptを1ファイルにまとめたもの) |
| `data.js` | 郵便番号データ(`build_data.py` で生成) |
| `build_data.py` | 日本郵便のCSVから `data.js` を作るスクリプト |

## データを最新にする

郵便番号データは日本郵便が毎月更新しています。最新版にするには:

1. [日本郵便の郵便番号データダウンロード](https://www.post.japanpost.jp/zipcode/download.html)から、**住所の郵便番号(1レコード1行、UTF-8形式)** の `utf_ken_all.csv` を取得します。
2. 次のコマンドで `data.js` を作り直します(Python 3 が必要)。

   ```bash
   python build_data.py utf_ken_all.csv
   ```

旧形式の `KEN_ALL.CSV`(Shift_JIS)にも対応しています。

`data.js` がない場合でも、`index.html` を開いて画面に CSV ファイルをドロップすれば、そのまま検索できます。ファイルはブラウザの中だけで読み込み、外部には送りません。

## データの出典

郵便番号データは[日本郵便株式会社](https://www.post.japanpost.jp/zipcode/download.html)が公開しているものを使っています。
